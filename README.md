# EDA-Grupal

Proyecto grupal de programación avanzada

## Descripción general
Este proyecto consiste en el desarrollo de una página web grupal para la presentación de un análisis exploratorio de datos (EDA) sobre el registro de nacidos vivos en Ecuador en el año 2023. El objetivo es aplicar técnicas de análisis y visualización de datos, utilizando Apache Zeppelin para la generación de gráficos y estadísticas relevantes.

## Estructura del repositorio

- `Proyecto_Sem11.zpln`: Archivo de proyecto de Apache Zeppelin, contiene notebook propio y análisis realizados.
- `web/`: Carpeta principal de la página web.
    - `index.html`: Página principal con introducción y enlaces de navegación.
    - `about.html`: Información sobre los integrantes del grupo y sus roles.
    - `article.html`: Artículo principal con resultados y visualizaciones del análisis de datos.
    - `desing.css`: Hoja de estilos con diseño moderno, fondo blanco y azul como color secundario.
